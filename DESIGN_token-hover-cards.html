The determinism answer

The SCIP card's rich fields are stored, not computed: the indexer (a real compiler pass) freezes the display name, kind, compiler-rendered signature, and the authored doc comment into the index; "defined at" and the references list are computed by the consumer by scanning occurrences for the Definition role bit. Same tree + same indexer version is stable in practice after canonicalization, but the format doesn't mandate byte-identity (parallel emit order is legal, absolute paths are embedded) and — decisive for us — the schema carries no content hash, timestamp, or staleness signal of any kind. Freshness is entirely our problem, which is why Tier 2 is opportunistic, never required.

Why not dumb-jump

We already are dumb-jump, specialized better: same ripgrep-plus-def-regex architecture, plus ranking our review context makes possible (same-file, changed-in-this-diff, test-penalty). It adds no capability class. The one asset worth mining is its ~305-rule, 60-language regex corpus to widen our def-pattern coverage beyond TS/JS/Py/Go/Rust.

Recommendation

Ship Tier 0 now, build Tier 1 as the innovation, treat Tier 2 as a freebie. Tier 0 is a UI feature over plumbing that exists — the card, debounce, and three cheap server enrichments. Tier 1 is where we beat the SCIP screenshot at its own game for a local tool: exact signatures and real doc comments with zero index and zero staleness, by parsing one file on demand with the tree-sitter runtime users already consent-install for Call Flow. Tier 2 costs us only a loader: teams that already produce SCIP in CI get the full deterministic experience, with our diff doing the position repair the format itself cannot.
Honesty rule carried from the rest of the product: the card always wears its source chip, heuristic results keep their "likely" label, capped reference lists say "50+", and Tier 2 data inside edited hunks is suppressed rather than shown wrong. A hover card that guesses confidently is worse than the References panel we have.

Sequencing: (1) card UI + Tier 0 enrichments, behind the same canUseLiveWorkspaceActions gate as today's code-nav, absent from the portable guides viewer by construction; (2) Tier 1 extractor + the Call Flow consent seam; (3) the SCIP loader; (4) optionally, mine dumb-jump's regex corpus to widen Tier 0's language coverage. Each step lands in both server runtimes per the two-runtime law.
