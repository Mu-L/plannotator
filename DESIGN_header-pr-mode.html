PR review header: agent ⇄ platform, current vs proposed

A PR review always carries the destination dropdown — the muted pill left of the actions (GitHub ▾ / Agent ▾, double-tap ⌥ to toggle). It decides where your review goes, and the whole action row swaps with it. Each destination routes to its own surface: agent actions go straight to the agent session (a toast confirms below), GitHub actions open the submission dialog. Flip the toggles, click everything.
