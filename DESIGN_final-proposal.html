The unified decision control — final proposal, every surface

One adaptive split control per header plus a ghost-✕ Close. Approve/Done and Send Feedback never render side by side, in any state. The caret carries the alternates and the note; the composer morphs inside the same popover; ⌘↩ always fires the visible primary. Everything below is live — labels, menus, confirms and toasts are the post-audit truth (this page supersedes the older mocks).

Compact / touch: the same spec generates the menu rows, so every state above has a visible positive action on phones too (no ⌘↩-only paths — the branch-review regression this prevents). The composer is a dialog there, never a textarea inside the menu. Sidebar: code review also gains a durable + General comment in the sidebar's General section (PR4) — creating one flips the header to Send Feedback · 1, which is the proof the control is state-driven.
